# Interactive Python Learning Platform (منصة مسار إتقان بايثون) 🐍

منصة تفاعلية متكاملة لتعليم لغة بايثون بتسلسل منهجي ذكي ونظام اجتياز مشروط.

> ⚡ **"كود متقن، منصة ذكية، وتجربة استثنائية.. وده يدلّ إنّ بشمهندس يوسف، بشمهندس مش عادي" 🚀👑**

---

## ✨ المميزات الرئيسية:
- **نظام فتح الدروس التدريجي (Gated Progression)**: لا يمكن للمتعلم فتح الدرس التالي إلا بعد اجتياز مهام الدرس الحالي.
- **مهام الدرس المباشرة (Direct Tasks)**: تطبيق مباشر على ما تم شرحه.
- **مهام المراجعة التراكمية (Cumulative Review Tasks)**: مهام شاملة تربط المفاهيم السابقة بالدرس الحالي لترسيخ التعلم.
- **ديناميكية المحتوى بالكامل (Dynamic Material)**: إضافة أي درس جديد بملف JSON بسيط داخل مجلد `lessons/` دون تعديل كود المنصة.
- **محرر أكواد وتصحيح تلقائي فوري**: تشغيل واختبار حلول المستخدم في بيئة محمية مع إظهار النتائج والتلميحات.

---
